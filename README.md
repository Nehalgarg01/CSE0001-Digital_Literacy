## Project Overview

This repository contains my portfolio as a Student Digital Ambassador. It demonstrates practical skills in digital literacy, including creating professional online profiles, maintaining safe and responsible digital communication, and understanding cybercrime prevention. The project is divided into five tasks, each corresponding to a module of the course.

## Repository Structure

* `report/` - Contains the final comprehensive Project Report (`.pdf` or `.docx`).

* `task-1-presentation/` - Contains the Digital Literacy Awareness Infographic.

* `task-2-portfolio/` - Contains screenshots of professional digital profiles (e.g., GitHub, LinkedIn).

* `task-3-platforms/` - Contains coding platform progress and Google Workspace collaboration artifacts.

* `task-4-email-etiquette/` - Contains professional email drafts and a social media Do's and Don'ts checklist.

* `task-5-cybercrime/` - Contains a cybercrime case study and a 'Stay Safe Online' prevention checklist.

## Module Summaries

### Module 1: Digital Literacy Awareness

Created a visual infographic highlighting the importance of digital literacy, safe internet practices, and useful tools for students.

### Module 2: Student Digital Portfolio

Established a foundational professional online presence across key platforms essential for employers and the academic community.

### Module 3: Coding & Collaboration Platforms

Explored online tools for studying, coding practice, and collaborating.

### Module 4: Professional Communication

Drafted professional emails (requesting an extension and applying for an internship) and created an actionable checklist for responsible social media usage as a college student.

### Module 5: Cybercrime Awareness & Prevention

Researched a specific cybercrime case study and developed a comprehensive prevention checklist, including financial safety tips and official reporting channels (National Cyber Crime Portal).
